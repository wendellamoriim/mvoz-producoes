# M Voz Produções

Produção audiovisual profissional em Portugal. Vídeos, podcasts, documentários, clipes musicais e fotografia.

## Tecnologias Utilizadas

- **Vite** - Build tool ultrarrápido
- **React** - Biblioteca Javascript para interfaces de usuário
- **TypeScript** - Tipagem estática segura
- **Tailwind CSS** - Framework CSS utilitário para design moderno
- **shadcn/ui** - Componentes de interface de usuário reutilizáveis e acessíveis

## Como Executar Localmente

Siga os passos abaixo para rodar o projeto em seu ambiente de desenvolvimento:

1. **Instalar Dependências**
   ```bash
   npm install
   ```

2. **Iniciar o Servidor de Desenvolvimento**
   ```bash
   npm run dev
   ```

3. **Gerar Versão de Produção**
   ```bash
   npm run build
   ```
